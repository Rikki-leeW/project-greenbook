Finally...

I'd like to officially add one sentence to our Sprig philosophy because I think we've earned it:

Purpose determines presentation. Relationships determine memory.

The first sentence has guided the look and feel of Sprig from the beginning.

The second should guide the architecture.

Because that's what we've been building today.

A garden isn't a collection of isolated facts.

It's a web of relationships.

If we continue following that idea, I genuinely think Sprig will end up feeling unlike any gardening app currently available. And the exciting part is that we're still laying those foundations before we've even built half the features. 🌱
