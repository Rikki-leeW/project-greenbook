============================================================

This is now an important global Sprig rule.

Sprig should NEVER force one duration unit globally or per feature.

Where Sprig displays age, elapsed time, duration or timing, the gardener should be able to choose:

• Days
• Weeks

• Plant Story age

• harvest timing/windows
• harvest age
• trials
• calendar timing
• “time since”
• comparable age/duration displays elsewhere

Current conversion convention:

Days:
exact rounded day count.

Weeks:
days / 7
display one decimal unless integer.

Months:
days / 30.4375
display one decimal unless integer.

19. PHOTO METADATA — IMPORTANT FIX ALREADY MADE
============================================================

There was an important bug involving duplicate image URLs.

Photo metadata must belong to the SAVED PHOTO ENTRY, not merely to an image URL.

The corrected lookup prefers exact aligned index first, then URL fallback.

Conceptually:

function getPhotoMetadata(
  photoUrl,
  index,
  photoMetadata,
) {
  const indexedMetadata =
    photoMetadata?.[index]

  if (indexedMetadata)
    return indexedMetadata

  return photoMetadata?.find(
    metadata =>
      metadata?.photoUrl === photoUrl
  )
}

DO NOT REVERT TO URL-FIRST LOOKUP.

That old behaviour caused duplicate URLs to load the wrong metadata.
