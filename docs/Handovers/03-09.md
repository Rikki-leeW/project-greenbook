CORE SPRIG PHILOSOPHY
------------------------------------------------------------

These principles are binding:

"New Sprig destination? Register it in the app map."

------------------------------------------------------------
GLOBAL INTERACTION RULE
------------------------------------------------------------

Anything that already exists as a saved record and is shown or mentioned elsewhere in Sprig should be directly accessible from the page the gardener is currently on.

GLOBAL EDITABILITY RULE
------------------------------------------------------------

Every user-entered or user-selected field should remain editable after saving.

------------------------------------------------------------
GLOBAL NAVIGATION RULE
------------------------------------------------------------

Saved/detail records should have TWO distinct navigation concepts whenever both are relevant:

1. JOURNEY BACK

2. HOME / CATEGORY ROUTE

"Back remembers the journey.
Home remembers where the record lives."

Do NOT assume persistent tabs or Satchel replace these routes.

Relationship navigation takes priority.

Example:

Back to Basic Compost

not:

because the gardener arrived through the relationship.
