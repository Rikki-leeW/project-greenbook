CSS law:

ONE VISUAL THING. ONE OBVIOUS CSS OWNER.

Examples:
- buttons.css = ordinary shared action-button appearance
- uniform-controls.css / appropriate form owner = canonical shared controls
- navigation.css = shared navigation
- photos.css = shared Photo System presentation
- plantcard.css = PlantCard-specific presentation
- layout.css = shared layout
- page CSS = genuinely page-specific composition/placement

Formula:

buttons.css owns WHAT the button looks like.
Page CSS owns WHERE the button goes.

Do NOT create page-specific CSS that recreates a shared control/navigation/button
merely because it is convenient.

Also audit for literal escaped pseudo-selectors if encountered, such as:
.nav-item\:hover
.nav-item\:focus-visible
body\:has(.form-backdrop)

Verify whether escaping genuinely exists in source before altering it.
